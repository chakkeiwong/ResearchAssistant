# Security Review Checklist

## Checklist

- data classification documented;
- no secrets in repository or plain local config;
- provider calls disabled by default;
- backup archives excluded from Git;
- private papers and local corpora excluded from Git;
- access control model reviewed;
- audit logs reviewed;
- incident response owner named;
- restore drill completed;
- dependency and vulnerability policy documented.

## Current Status

This checklist is a release gate. It is not itself security approval.
